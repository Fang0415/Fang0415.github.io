# Sunflower Skill Assets — v1

这组素材来自 Skill Repository 方向探索，当前不再继续作为该模块的最终视觉方案，但保留供后续页面装饰、交互实验或其他模块复用。

## 原始素材

- `source-sunflower.png`：用户提供的完整向日葵原图，1024 × 1536，RGBA。
- `source-petal-magenta.png`：用户提供的独立花瓣原图，1717 × 916，洋红背景。

## 可直接复用的处理版本

- `sunflower-composite.png`：此前确认过的完整合成版本。
- `sunflower-right-open-base.png`：移除右半侧花瓣后的主体，适合叠加交互花瓣。
- `sunflower-clean-disk.png`：去除外围花瓣碎片的纯花盘透明层。
- `petal-transparent.png`：从洋红背景中提取出的透明花瓣。

## 原交互设定

- 花瓣沿花盘右半圆分布。
- 选中花瓣沿自身径向抽出约 12px。
- 选中状态增加亮度、饱和度，并轻微放大。
- 花盘透明层置于花瓣根部上方，用于隐藏根部接缝。

## 状态

Archived / not currently selected for the Skill Repository UI.
